# Results Directory

## Purpose

This directory is reserved for documentation about analysis outputs. The complete NGS analysis results are stored in the local workspace:

`/home/MAYANK/NGS2/result/`

The GitHub repository does not contain the complete FASTQ dataset, reference genome, alignment files, intermediate variant files, or full analysis outputs.

## Local Result Categories

The local `NGS2/result/` directory contains:

- `qc/` — raw and post-trimming FastQC reports and fastp outputs.
- `alignment/` — SAM/BAM alignment files and sorted BAM/index files.
- `alignment_qc/` — mapping and alignment statistics.
- `variants/` — raw and filtered variant calls, annotated VCF, variant tables, and SnpEff summaries.
- `candidate_review/` — candidate-site read evidence and review metrics.

## Recorded Run

The documented run produced 7 raw variant records and 5 filtered variant records. These counts are preliminary computational outputs and do not establish independent validation or biological significance.

For interpretation guidance, see `../docs/results_interpretation.md`.

## Accessing Results

To inspect the results on the original machine:

```bash
ls -lah /home/MAYANK/NGS2/result/
```

The local result files are generated by the scripts and are not automatically included when someone clones the GitHub repository.
